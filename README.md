# 🚀 Gitnaut

**Learn Git by doing, not by memorizing.**

Gitnaut is an interactive, space-themed Git course. Fix real repo problems, watch commits form in 3D, and ask an AI tutor when you're stuck.

## ✨ What's inside

- 📚 **8 stages**, from `git init` to rebase and tags
- ⌨️ **37 commands**, each explained in plain English
- 🛰️ **Missions** that fix leaked secrets and merge conflicts
- 🌠 **3D commit graphs** you can explore
- 🤖 **Ask Gitnaut AI**, a tutor that answers in simple words
- 🔥 **Streaks and XP** to keep you going
- 📋 **Cheat sheet** with one-click copy

## 🚀 Run it

```bash
git clone https://github.com/sharanyashetty013-droid/gitnaut.git
cd gitnaut
npm install
cp .env.example .env   # add your GEMINI_API_KEY
npm run dev
```
